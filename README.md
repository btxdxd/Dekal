# 🚀 Dekal (Native Bootstrap & Updater)

Нативный загрузчик и автоапдейтер для игрового лаунчера, скомпилированный с помощью **GraalVM Native Image** в легковесный исполняемый файл (`.exe`). Не требует установленной Java на ПК пользователя, сам скачивает изолированную JRE, обновляет лаунчер и бесшовно запускает игру.

> [!NOTE]
> Пакет `btxds.dekal.util` содержит в себе движок валидации целостности файлов (`FileChecker` и `HashChecker`), сверяющий локальные SHA-256 хеши с удаленным эндпоинтом Dekal Transmitter.

---

### 🚀 Как это работает

```text
dbd-project.exe (GraalVM Native) ──► Захват AppLock (single-instance)
      │
      ├──► Проверка/Загрузка JRE (сверка .hash) ──► распаковка в /jre
      ├──► Проверка/Загрузка launcher.jar (сверка SHA-256)
      │
      └──► Бесшовный запуск: jre/bin/javaw.exe -jar launcher.jar
```

1. **`AppLock`**: Блокирует повторные запуски приложения через `dekal.lock`.
2. **`FileChecker` / `HashChecker`**:
    * Запрашивает актуальный SHA-256 хеш с эндпоинта `/<file>/hash`.
    * Вычисляет локальный хеш `launcher.jar` и проверяет наличие валидного рантайма JRE (`javaw.exe` / `java`).
3. **`DownloadManager`**: Скачивает недостающие файлы во временные `.tmp` и атомарно заменяет их, распаковывая JRE.
4. **Запуск**: Стартует `launcher.jar` через только что проверенную локальную JRE без отображения лишних консольных окон.

> [!IMPORTANT]
> Приложение компилируется в нативный Windows GUI-бинарник (`/SUBSYSTEM:WINDOWS`), благодаря чему запуск происходит мгновенно и без всплывающих черных окон командной строки.

---

### 🔍 Движок утилит (`btxds.dekal.util`)

> [!TIP]
> * **`HashChecker`**: Потоковый расчет SHA-256 без загрузки всего файла в память и запрос удаленных хешей через нативный `HttpClient`.
> * **`FileChecker`**: Кроссплатформенная валидация структуры среды исполнения (`jre/bin/javaw.exe`) и проверка версий через локальный `.hash`.

---

### ⚙️ Сборка в Native Image

Для сборки нативного `.exe` требуется **GraalVM JDK 21+** с установленным инструментом `native-image` (и Visual Studio C++ Build Tools на Windows):

```bash
# Сборка нативного исполняемого файла
./gradlew nativeCompile
```
Готовый бинарник `file-name.exe` будет создан в каталоге:
`build/native/nativeCompile/`

---

> [!WARNING]
> Адрес хоста обновлений и имена целевых файлов задаются в [Config.java](src/main/java/btxds/dekal/Config.java). Сервер должен отдавать SHA-256 по эндпоинту `https://<host>/<file>/hash`.
